# Jumping Ninja v1.0.7

本次更新修复了几个影响游玩的移动端问题。

## 更新内容

- 白色外墙按整段生成连续碰撞体，减少高速下落时卡在墙体接缝上的情况。
- 开局会等待玩家首次点击左侧或右侧后才开始下落和跳跃。
- 优化密码输入框的移动端软键盘配置，提升 Xiaomi 等设备的兼容性，同时保留密码遮罩。

## 下载

- Android：下载 `JumpingNinja-v1.0.7.apk` 后安装。Version Name 为 `1.0.7`，Version Code 为 `7`。
- Windows：下载 `JumpingNinja-v1.0.7-Windows.zip`，完整解压后运行 `Jumping Ninja.exe`。

Android APK 仍使用调试证书签名，Windows EXE 未进行代码签名。在线功能需要连接 Jumping Ninja 服务器。

## 测试范围

- Unity `6000.5.9f1` 脚本编译与 `V1ProjectSetup.ValidateV1` 校验通过。
- 已执行 Android APK 与 Windows x64 构建及产物哈希校验。
- 未执行 Xiaomi 真机输入、Android 安装或 Windows GUI 玩法测试。
