# Jumping Ninja v1.0.5

本版本改善了 Windows 窗口与键盘操作体验，并同时提供 Android 与 Windows 下载。

- Windows 窗口现在可以自由调整大小。
- 游戏画面始终保持 9:16；窗口多余区域自动以黑色补齐，不会拉伸画面。
- 每个菜单会自动选中常用按钮，并显示金色选中边框。
- 可用方向键在按钮间移动，按 Enter 触发当前按钮；鼠标点击和手机触控保持不变。
- 游戏中的 A / D、左右方向键及左右半屏操作保持不变。

下载说明：

- Android：下载 `JumpingNinja-v1.0.5.apk` 后安装。Version Name 为 `1.0.5`，Version Code 为 `5`。
- Windows：下载 `JumpingNinja-v1.0.5-Windows.zip`，完整解压后运行 `Jumping Ninja.exe`。

签名说明：Android APK 当前使用 Debug 证书签名；Windows EXE 未进行代码签名。
