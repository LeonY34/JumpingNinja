# Jumping Ninja v1.0.6

这次更新加入在线账号和排行榜功能，并完成一轮安全检查与服务端依赖加固。

## 更新内容

- 支持注册、登录 Jumping Ninja 在线账号。
- 支持创建和切换云端忍者，并可导入旧版本地忍者。
- 加入账号排行榜、目标忍者提示和最佳成绩同步。
- 服务端 ASP.NET Core / EF Core 更新到 10.0.11，Npgsql 更新到 10.0.3。
- 服务端容器改为非 root 运行，并补充反向代理安全响应头配置。

## 下载

- Android：下载 `JumpingNinja-v1.0.6.apk` 后安装。Version Name 为 `1.0.6`，Version Code 为 `6`。
- Windows：下载 `JumpingNinja-v1.0.6-Windows.zip`，完整解压后运行 `Jumping Ninja.exe`。

Android APK 仍使用调试证书签名，Windows EXE 未进行代码签名。首次运行在线功能需要连接 Jumping Ninja 服务器。
