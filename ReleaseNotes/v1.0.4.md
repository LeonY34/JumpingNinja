# Jumping Ninja v1.0.4

## 更新内容

- 游戏中现在可以使用 `A` / `D` 或左 / 右方向键控制忍者跳跃。
- 原有的左右半屏点击控制保持不变，游戏内提示文字也保持不变。
- 新增 Windows x64 竖屏窗口版本。

## 下载说明

- Android：下载 APK 后安装。Version Name 为 `1.0.4`，Version Code 为 `4`。
- Windows：下载 ZIP 并完整解压，然后运行 `Jumping Ninja.exe`。

Android APK 使用 Debug 证书签名，Windows EXE 未进行代码签名，系统可能显示安全提醒。本版本执行了 Unity 双平台构建和产物检查，未进行手机安装或真机玩法测试。
