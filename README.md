# Jumping Ninja

Potatoed Mice 制作的开源竖屏 2D 跳跃小游戏。控制方形忍者左右跳跃，避开危险方块并不断向上攀登。

## 下载

[下载 Android APK（v1.0.3）](https://github.com/LeonY34/JumpingNinja/releases/download/v1.0.3/JumpingNinja-v1.0.3.apk)

> 当前 APK 使用 Android Debug 证书签名，适合直接体验；本版本未进行真机玩法测试。

## 开发

- Unity：`6000.5.9f1`
- 平台：Android，竖屏，ARM64 / IL2CPP
- 打开项目后运行 `Assets/Scenes/SampleScene.unity`

设计要求见 [GAME_PROMPT.md](GAME_PROMPT.md)，当前开发状态见 [GAME_STATUS.md](GAME_STATUS.md)。
